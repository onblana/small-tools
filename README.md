### TenMinuteSnapAlarm_by_blana.html
10분 단위로 집중할 수 있게 해주는 조용한 알람
- 현재 시간을 기준으로 다음 10분 단위 시각이 설정됨 (예: 15:12 → 15:20)
- `+10분` 버튼으로 목표 시각을 10분씩 추가
- 목표 시각이 이미 지난 경우는 시작 버튼 비활성화
- **시작 버튼 클릭 후에는 남은 시간을 표시하지 않으며**, 배경이 시계 바늘처럼 차오르는 효과로 남은 시간을 나타냄
- 알람 사운드 없음, 타이머 종료 시 새로고침 아이콘이 깜빡이며 시각적으로만 표시됨

# Simple Tools by onblana

Small, simple tools I made for myself.

## Tools

### TenMinuteSnapAlarm_by_blana.html
A quiet alarm that helps you focus in 10-minute blocks.
- Defaults to the next 10-minute mark based on the current time (e.g. 15:12 → 15:20).
- `+10min` button adds 10 minutes to the target time.
- Start button is disabled if the target time has already passed.
- **After you hit start, the remaining time isn't shown** — the background fills up like a clock hand instead.
- No alarm sound; when it finishes, only a blinking refresh icon shows it visually.

### SimpleTimer_by_blana.html
A quiet countdown timer that won't break your focus.
- Set minutes and seconds, or pick a quick preset (10, 9:30, 9, 8:30, 8 min).
- **After you hit start, the remaining time isn't shown** — the background fills up like a clock hand instead.
- No alarm sound; when it finishes, only a blinking refresh icon shows it visually.

## Usage
Just download the `.html` file and open it. Plain HTML + vanilla JS only, nothing shady in it.
The files are simple enough — feel free to open and read them yourself.
